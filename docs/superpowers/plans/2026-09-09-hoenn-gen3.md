# Hoenn (Gen 3 — Émeraude) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the complete Hoenn region (Generation 3, Pokémon Emerald reference) to the game, including 135 species (252-386), canonical Emerald encounter tables, 9 roguelite acts, 8 Gym Leaders, Elite Four + Wallace, Steven Stone epilogue boss, roaming and static legendaries, WebAudio cries, and UI integration while preserving 100% determinism and bit-level non-regression for Gen 1 and Gen 2.

**Architecture:** Pure Vanilla JS (ES5 IIFE modular pattern) with strict `NOYAU` (headless, pure simulation, zero DOM, zero non-deterministic calls) vs `ECRANS` (presentation, WebAudio synth, DOM rendering) separation. Data and journey logic are encapsulated in `js/poke/gen3/`, registered via the single source of truth in `ordre.js` and the polymorphic registry `PokeRegles` in `regles.js`.

**Tech Stack:** Vanilla JavaScript (ES5 / IIFE), HTML5, CSS3, WebAudio API, Node.js test harness (`tests/run_all_tests.mjs`).

**Spec:** [`docs/superpowers/specs/2026-09-09-hoenn-gen3-design.md`](file:///c:/Users/illye/Documents/antigravity/rtl-pokemon/docs/superpowers/specs/2026-09-09-hoenn-gen3-design.md)

## Global Constraints
- Zero external runtime dependencies.
- Zero DOM access, zero `document`, zero `window` inside `NOYAU` (`js/poke/gen3/` core files).
- Zero calls to `Math.random()`, `Date.now()`, `new Date()`, `performance.now()` in `NOYAU`.
- PRNG determinism contract: Gen 1 and Gen 2 combat replay scores and seeds must produce identical bit-level results.
- Single source of truth for script ordering preserved in [`js/poke/ordre.js`](file:///c:/Users/illye/Documents/antigravity/rtl-pokemon/js/poke/ordre.js).
- National Pokédex account total extended to 386 (`dexTotalCompte: 386`).
